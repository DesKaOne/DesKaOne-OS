# Security Policy

**Current status:** Architecture-only project. No supported binaries, images or releases exist yet.

## Reporting a vulnerability
Please do **not** disclose sensitive exploit details in public Issues. Use GitHub's **Report a vulnerability** / private vulnerability reporting feature if enabled on this repository. If it is unavailable, request a private contact channel from the maintainers without sharing exploit details publicly.

Include affected component or design, reproduction conditions, potential impact and suggested mitigation when safe.

## Scope
At this stage, security reviews of planned package signing, management interfaces, privilege separation, update safety and network rollback are welcome.

No response-time SLA or production security support is promised until the project establishes a staffed security process.
